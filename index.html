Sincronización en la nube

Guarda tus movimientos en un gist secreto de GitHub para acceder a los mismos datos desde cualquier dispositivo. El gist es privado: solo accesible con tu token. Necesitás un token con permiso únicamente sobre gists. Crear token → (marcá solo gist, sin fecha de expiración o la que prefieras).
Se guarda solo en este navegador. Nunca se envía a otro lado que no sea la API de GitHub.
Para conectar un segundo dispositivo, copiá acá el ID que aparece en el primero.

Ajuste de saldo por cuenta

El efectivo ya se calcula solo a partir de los movimientos (ventas y rentas acreditan; compras, gastos y retiros debitan). Usá esto solo para la diferencia contra el extracto del bróker: saldo inicial anterior al primer movimiento cargado, o algo que quedó sin registrar. Los valores negativos (descubierto, caución tomadora) se restan del total de la cartera.
Si cargaste la misma cuenta con nombres distintos, renombrá una al nombre de la otra para fusionar las posiciones.
